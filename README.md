# Controle Financeiro

Quinto projeto do portfólio de Marcelo Andrade.

## Estado atual

Repositório criado em 16/10/2026. Em planejamento; aguardando as inspirações visuais do autor antes de definir identidade, telas e implementação.

## Proposta inicial para discussão

- Entradas e saídas com categorias.
- Filtros por período e resumo financeiro.
- Dashboard responsivo para desktop e celular.
- Demonstração pública com dados fictícios.

Esses itens são propostas, não funcionalidades implementadas. Nome da marca, paleta e escopo final ainda serão definidos.

## Base técnica prevista

Next.js, React, TypeScript e Tailwind CSS, com futura publicação na Vercel após implementação e validação.

Sem deploy nesta etapa. Nenhuma integração bancária ou transação financeira real está implementada.
